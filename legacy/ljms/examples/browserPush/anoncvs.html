Anonymous CVS Access

This project's CVS repository can be checked out through anonymous (pserver):

cvs -z3 -d:pserver:anonymous@cvs.ljms.sourceforge.net:/cvsroot/ljms co common


or any directory inside module common. For example, for checking out logmanager sources, do the following:

cvs -z3 -d:pserver:anonymous@cvs.ljms.sourceforge.net:/cvsroot/ljms co common/src/org/is/logmanager
(directories common/src/org/is will be created automatically) in your local directory.

Developer CVS Access via SSH

Only project developers can access the CVS tree via this method. SSH1 must be installed on your client machine. Substitute developername with the proper value. Enter your site password when prompted.

export CVS_RSH=ssh
cvs -z3 -d:ext:developername@cvs.ljms.sourceforge.net:/cvsroot/ljms co common
